How To Play

Goal

Guess the secret word before your opponent does. You take turns guessing the same word, and both players see the same board and history.

Setup

  1. Host Game: One player clicks “Host Game”, enters a name, and gets a Game ID.
  2. Share ID: The host sends the Game ID to the opponent.
  3. Join Game: The opponent clicks “Join Game”, enters their name and the Game ID.
  4. Start Match: Once both players are connected, the host clicks “Start Match”.

Taking Turns

  • Players alternate turns making one guess at a time.
  • The “Current turn” label shows whose turn it is (by name).
  • Both players see every guess on the shared board in the order they were made.

Tile Colors

  • Green: Correct letter in the correct position.
  • Yellow: Letter is in the word, but in a different position.
  • Gray: Letter is not in the word.

Keyboard

Use the on-screen keyboard or your physical keyboard to type guesses. The keyboard keys are colored using the best information you’ve discovered so far (green > yellow > gray).

Invalid Words

If you enter a word that is not in the dictionary, you’ll see an error message and your tiles will not update. You can correct the word and try again.

Winning, Rematching, Exiting

  • The first player to guess the secret word wins.
  • After the game ends, you can choose Rematch to start a new game with a new word.
  • Choose Exit to return to the main menu.
